# Deposit Manager

[↩ Прикладные проекты](https://github.com/levg00/levg00/blob/main/portfolio/applied.ru.md) · [Видеодемонстрация](https://youtu.be/P-Ue0A0f01Q)

Консольное приложение на Python для учёта доходов и расходов. Позволяет просматривать историю операций, сортировать суммы и экспортировать данные в CSV.

Финальный учебный проект курса **CS50's Introduction to Programming with Python (CS50P)**. Автор — Лев Гирин.

## Возможности

- Добавление доходов и расходов с необязательным описанием.
- Расчёт текущего баланса после каждой операции.
- Просмотр истории с промежуточным балансом.
- Вывод доходов и расходов в двух колонках, каждая отсортирована по убыванию суммы.
- Экспорт истории в CSV: в исходном порядке или с общей сортировкой по сумме.
- Итоговый баланс и средняя сумма доходной и расходной операции в экспортируемых файлах.

## Инструменты и устройство

**Python 3 · стандартный модуль `csv` · pytest для тестов.** Для запуска приложения внешние библиотеки не нужны.

Программа построена на функциях. Командный цикл разбирает ввод и вызывает операции добавления, списания, просмотра и экспорта. Баланс и история хранятся в памяти текущего процесса; операции представлены кортежами в списке.

Проект объединяет обработку строк, работу с коллекциями, сортировку, файловый ввод-вывод и базовое тестирование.

## Запуск

Из папки проекта:

```bash
python3 project.py
```

Если Python 3 доступен в системе под командой `python`, используй `python project.py`.

После запуска введи `help`, чтобы увидеть список команд. Интерфейс приложения — на английском.

## Пример использования

Вводи команды по очереди внутри программы:

```text
add $500 salary
withdraw $125 food
print history
export csv
exit
```

После этих операций баланс составит `$375.0`. Команда `export csv` создаст файл `history.csv` в текущей рабочей папке.

| Команда | Действие |
| :--- | :--- |
| `add $100 salary` или `+$100 salary` | Добавить доход |
| `withdraw $50 food` или `-$50 food` | Добавить расход |
| `print history` | Показать операции и промежуточный баланс |
| `print sorted history` | Показать доходы и расходы отдельно, по убыванию суммы |
| `export csv` | Экспортировать историю в `history.csv` |
| `export sorted csv` | Экспортировать операции по убыванию суммы в `sorted.csv` |
| `help` | Показать справку |
| `exit` | Завершить программу |

Описание операции необязательно. Для дробных сумм используется точка.

## Экспорт

`history.csv` содержит поля `Action`, `Amount`, `Description`, `Balance`; `sorted.csv` — `Action`, `Amount`, `Description`. В конце каждого файла добавляются итоговый баланс и средние суммы доходных и расходных операций. Это среднее на операцию, а не за день или месяц.

Примеры ранее сформированных файлов находятся в папке [`examples`](examples). Программа не загружает их автоматически.

**Повторный экспорт перезаписывает одноимённый файл.** Для сохранения нескольких сессий переименовывай или копируй результаты.

## Тесты

Установи pytest в своё окружение и запусти существующие тесты:

```bash
python3 -m pip install pytest
python3 -m pytest -q test_project.py
```

В исходном наборе семь тестов. Проверяются добавление дохода, списание расхода и текст справки. Четыре других теста вызывают функции вывода и экспорта, но пока не проверяют содержимое результата. Успешное прохождение набора не означает полную проверку поведения программы.

Тесты экспорта создают `history.csv` и `sorted.csv` в рабочей папке и могут перезаписать существующие файлы.

## Ограничения учебной версии

- История и баланс сбрасываются после завершения программы. CSV можно сохранить отдельно, но обратный импорт не реализован.
- Для сумм используется `float`, поэтому возможны погрешности представления дробных чисел.
- Проверка входных данных неполная: отрицательные и специальные числовые значения не отклоняются; неизвестная команда завершает программу с ошибкой.
- Весь введённый текст, включая описание операции, переводится в нижний регистр.
- Символ `$` задан в интерфейсе; поддержки нескольких валют и дат операций нет.

## Возможные улучшения

- Перейти на `Decimal` для денежных сумм.
- Проверять допустимость сумм и обрабатывать ошибочные команды без завершения сеанса.
- Добавить сохранение и загрузку истории между запусками.
- Проверять содержимое вывода и CSV в тестах, изолировать состояние каждого теста.
