Консольное приложение на Python для учёта доходов и расходов. Позволяет просматривать историю операций, сортировать суммы и экспортировать данные в CSV.

Финальный учебный проект курса **CS50's Introduction to Programming with Python (CS50P)**.

[Видеодемонстрация проекта](https://youtu.be/P-Ue0A0f01Q)

## Инструменты и устройство

**Python 3 · стандартный модуль `csv` · pytest для тестов.** Для запуска приложения внешние библиотеки не нужны.

Программа построена на функциях, операции в командной строке разбирают ввод и вызывают операции добавления, списания, просмотра и экспорта. Баланс и история хранятся в памяти текущего запуска.

Проект объединяет:
- Обработку строк
- Работу с коллекциями
- Сортировку
- Файловый ввод-вывод 
- Тестирование

## Запуск

Из папки проекта:

```bash
python3 project.py
```

После запуска введи `help`, чтобы увидеть список команд. Интерфейс приложения на английском.

## Основные функции

| Функция | Назначение |
| :--- | :--- |
| `main()` | Запускает командный цикл: принимает ввод и вызывает соответствующую функцию. |
| `add_money(inp)` | Разбирает сумму и описание дохода, увеличивает баланс и добавляет запись в историю. |
| `withdraw_money(inp)` | Разбирает сумму и описание расхода, уменьшает баланс и добавляет запись в историю. |
| `print_history()` | Выводит операции в порядке добавления с балансом после каждой операции. |
| `print_sorted()` | Разделяет доходы и расходы, сортирует каждую группу по убыванию суммы и выводит их в двух колонках. |
| `export_csv()` | Записывает историю и промежуточные балансы в `history.csv`, добавляет итоговый баланс и средние суммы операций. |
| `export_sorted_csv()` | Сортирует общую историю по убыванию суммы и записывает её в `sorted.csv`, добавляя итоговый баланс и средние суммы операций. |
| `show_help()` | Возвращает текст справки с доступными командами. |

Текущее состояние хранится в двух глобальных переменных:
- `balance` — текущий баланс;
- `history` — список операций в формате `(тип, сумма, описание)`, где тип — `"+"` для дохода или `"-"` для расхода.

## Экспорт

`history.csv` содержит поля `Action`, `Amount`, `Description`, `Balance`; `sorted.csv` — `Action`, `Amount`, `Description`. В конце каждого файла добавляются итоговый баланс и средние суммы доходных и расходных операций.

**Повторный экспорт перезаписывает одноимённый файл.** Для сохранения нескольких сессий переименовывай или копируй результаты.

## Тесты

Существующие тесты:

```bash
python3 -m pip install pytest
python3 -m pytest -q test_project.py
```

В проекте представлены семь тестов. Проверяются добавление дохода, списание расхода и текст справки. Четыре других теста вызывают функции вывода и экспорта, но пока не проверяют содержимое результата.

Тесты экспорта создают `history.csv` и `sorted.csv` в рабочей папке и могут перезаписать существующие файлы.

## Пример использования

Вводим команды по очереди внутри программы:

```text
add $500 salary
withdraw $125 food
print history
export csv
exit
```

После этих операций баланс составит `$375.0`. Команда `export csv` создаст файл `history.csv` в текущей рабочей папке.

| Команда | Действие |
| :--- | :--- |
| `add $100 salary` или `+$100 salary` | Добавить доход |
| `withdraw $50 food` или `-$50 food` | Добавить расход |
| `print history` | Показать операции и промежуточный баланс |
| `print sorted history` | Показать доходы и расходы отдельно, по убыванию суммы |
| `export csv` | Экспортировать историю в `history.csv` |
| `export sorted csv` | Экспортировать операции по убыванию суммы в `sorted.csv` |
| `help` | Показать справку |
| `exit` | Завершить программу |


## Ограничения учебной версии

- История и баланс сбрасываются после завершения программы. CSV можно сохранить отдельно, обратный импорт не реализован.
- Для сумм используется `float`, поэтому возможны погрешности представления дробных чисел.
- Проверка входных данных неполная: отрицательные и специальные числовые значения не отклоняются. Неизвестная команда завершает программу с ошибкой.
- Весь введённый текст, включая описание операции, переводится в нижний регистр.
- Символ `$` задан в интерфейсе; поддержки нескольких валют и дат операций нет.

## Возможные улучшения

- Перейти на `Decimal` для денежных сумм.
- Проверять допустимость сумм и обрабатывать ошибочные команды без завершения сеанса.
- Добавить сохранение и загрузку истории между запусками.
- Проверять содержимое вывода и CSV в тестах, изолировать состояние каждого теста.
