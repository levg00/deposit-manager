[↩ Прикладные проекты](https://github.com) 



Консольное приложение на Python для учёта доходов и расходов. Позволяет просматривать историю операций, сортировать суммы и экспортировать данные в CSV.

Финальный учебный проект курса **CS50's Introduction to Programming with Python (CS50P)**.



### 📺 [`Демо проекта`](https://youtu.be)


<br>


## 🛠️ Инструменты и устройство

* **Язык:** Python 3 (без внешних зависимостей)
* **Модули:** Стандартный модуль `csv` для работы с данными
* **Тестирование:** Библиотека `pytest` для автоматических тестов



### ⚡ Примененные навыки
* **Потоковый ввод-вывод (I/O):** Реализовал потоковую запись данных и генерацию структурированных финансовых отчетов в формате CSV.
* **Алгоритмы и структуры данных:** Разработал сортировку коллекций по убыванию сумм для раздельного вывода транзакций.
* **Обработка строк:** Спроектировал парсинг пользовательского ввода в интерактивном CLI-интерфейсе.
* **Автоматическое тестирование (QA):** Покрыл ключевой функционал юнит-тестами с помощью фреймворка `pytest`.


<br>


## Запуск

Из папки проекта:

```bash
python3 project.py
```

После запуска введи `help`, чтобы увидеть список команд. Интерфейс приложения на английском.



<br>



## ⚙️ Основные функции

<details>
<summary><b>📂 Архитектура функций</b></summary>

| Функция | Назначение |
| :--- | :--- |
| `main()` | Запускает командный цикл: принимает ввод и вызывает соответствующую функцию. |
| `add_money(inp)` | Разбирает сумму и описание дохода, увеличивает баланс и добавляет запись в историю. |
| `withdraw_money(inp)` | Разбирает сумму и описание расхода, уменьшает баланс and добавляет запись в историю. |
| `print_history()` | Выводит операции в порядке добавления с балансом после каждой операции. |
| `print_sorted()` | Разделяет доходы и расходы, сортирует каждую группу по убыванию суммы и выводит их в двух колонках. |
| `export_csv()` | Записывает историю и промежуточные балансы в `history.csv`, добавляет итоговый баланс и средние суммы операций. |
| `export_sorted_csv()` | Сортирует общую историю по убыванию суммы и записывает её в `sorted.csv`, добавляя итоговый баланс и средние суммы операций. |
| `show_help()` | Возвращает текст справки с доступными командами. |

</details>


Текущее состояние хранится в двух глобальных переменных:
- `balance` — текущий баланс;
- `history` — список операций в формате `(тип, сумма, описание)`, где тип — `"+"` для дохода или `"-"` для расхода.


<br>




## 💾 Экспорт данных

`history.csv` содержит поля `Action`, `Amount`, `Description`, `Balance`; `sorted.csv` — `Action`, `Amount`, `Description`. В конце каждого файла добавляются итоговый баланс и средние суммы доходных и расходных операций.


> ⚠️ **Важно:** Повторный экспорт полностью перезаписывает одноимённый файл в директории. Для сохранения нескольких сессий переименовывайте результаты вручную.


<br>




## 🧪 Тестирование проекта

Для запуска тестов вам понадобится установленный `pytest`. Выполните в консоли:

```bash
python3 -m pip install pytest
python3 -m pytest -q test_project.py
```


В проекте представлены **7 автоматических тестов**, проверяющих базовую логику добавления доходов, списания расходов и вывода текста справки.


> ⚠️ **Важно:** Тесты экспорта создают `history.csv` и `sorted.csv` в рабочей папке и могут перезаписать существующие файлы.




<br>


## Пример использования

```bash
\$ python3 project.py

> add \$500 salary
[+] Added: \$500.0 (salary)

> withdraw \$125 food
[-] Withdrew: \$125.0 (food)

> print history
--- HISTORY ---
+ \$500.0 | salary
- \$125.0 | food
Current Balance: \$375.0

> export csv
[✔] Success: history.csv saved!
```




<br>


> [!WARNING]  
> **Ограничения учебной версии:**
> * **Память:** История и баланс сбрасываются после завершения программы.
> * **Точность:** Для сумм используется `float`, поэтому возможны погрешности представления дробных чисел.
> * **Валидация:** Проверка входных данных неполная, некорректные значения не отклоняются.
